Find and replace

Paste your text, enter what to find and what to replace it with. All processing happens locally in your browser.

Find and replace is one of those tiny operations you need almost every day: renaming a variable across a code snippet, switching a product name in a long email template, cleaning up inconsistent capitalisation in a spreadsheet export, or removing stray whitespace from scraped data. Doing it by hand in a text editor is error prone because you lose track of how many replacements you have already made. This page performs true bulk replacement and, more importantly, reports exactly how many matches were found and how many remain afterwards.

Three options cover almost every real world use case. Regex switches the "find" field into a JavaScript regular expression, so patterns like \d{3}-\d{3}, \s+ or (?<name>\w+) work as expected, and capture groups can be referenced in the replacement with $1, $2 and so on. Case sensitive decides whether "Apple" and "apple" are the same needle. Whole word wraps the pattern in word boundaries so replacing "cat" never damages "category" or "concatenate".

Everything is executed by JavaScript in your own tab - the text is never transmitted to a server, no request is logged, and the page even works after you go offline. That makes it safe for pasting customer data, internal documents, source code or configuration files. Use the Copy button to put the result straight onto your clipboard, or count matches first to sanity check a destructive replacement before you run it.

Frequently asked questions

Does the find and replace tool upload my text?

No. The replacement runs in JavaScript inside your browser tab. Nothing is sent to any server, so the page keeps working offline and is safe for confidential text.

Which regular expression flavour is supported?

The tool uses the browser native JavaScript RegExp engine, which supports character classes, quantifiers, lookahead, lookbehind (in modern browsers), named groups and the $1..$n backreferences in the replacement string.

Why did the whole-world option not match part of a word?

Whole word mode adds \b word boundaries around your search term. A word boundary only exists between a word character (letters, digits, underscore) and a non-word character, so "cat" will not match inside "category".

Can I replace with an empty string to delete matches?

Yes. Leave the replace field empty and press Replace all - every match is removed. Use the Count matches button first if you want to verify how many occurrences exist.

Is there a limit on the amount of text?

The practical limit is your browser tab memory. Texts of a few megabytes replace instantly; extremely large texts (tens of megabytes) may take a second or two.
