Markdown to HTML Converter

Paste Markdown on the left and get HTML on the right, live as you type. Everything is converted locally in JavaScript, so drafts and internal notes never leave your machine.

What Markdown actually is

Markdown is a lightweight plain-text syntax written by John Gruber in 2004 so that documents stay readable before and after rendering. Where HTML needs explicit tags, Markdown infers structure from punctuation: a leading # makes a heading, a blank line separates paragraphs, **bold** sets strong emphasis and a leading - starts a list. Because the source is still plain text, it survives email, chat, code review and version control without turning into tag soup, which is why README files, issue trackers and note apps all converged on it.

CommonMark, GFM and the flavors

The original specification was informal, so implementations disagreed on edge cases. CommonMark (2014) closed that gap with a rigorous spec and a test suite, and GitHub Flavored Markdown (GFM) added the features most people now expect: fenced code blocks with language hints, tables, task lists with checkboxes, strikethrough with double tildes and autolinks. This converter implements the GFM subset you meet daily — headings, emphasis, lists, task lists, tables, fenced code, blockquotes, rules, images and links. Inline code is protected before other rules run, so a literal asterisk inside backticks stays an asterisk.

Safety and escaping

HTML is escaped before any tag is generated, which means raw markup you paste stays text instead of executing. That is the right default for a preview tool: it stops draft content from running scripts in your browser. When you embed the generated HTML in a CMS, review it as you would any pasted HTML, and sanitise it server-side if the source is untrusted. If you need the reverse direction, the Markdown editor lets you write and preview in one pane, and the HTML entities tool helps when you must display literal angle brackets.
