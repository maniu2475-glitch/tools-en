About this tool

URLs may only contain a small set of unreserved ASCII characters. Everything else — spaces, non-Latin letters, emoji, ?, &, # — must be percent-encoded: each byte of the UTF-8 representation becomes a % followed by two hex digits. The space character can be written as %20 or, in form submissions, as +. JavaScript exposes two encoding functions with subtly different rules. encodeURIComponent() escapes everything except A-Z a-z 0-9 - _ . ! ~ * ' ( ), so it is the correct choice for encoding a single query-string value. encodeURI() leaves ; / ? : @ & = + $ , # intact, so it is used when normalising a complete URL where the structural characters must survive. Using the wrong one is the most common cause of double-encoding bugs and broken redirect parameters. On the decode side, decodeURIComponent() throws a URIError on malformed input such as a lone % or invalid UTF-8 sequences, which this tool catches and reports instead of silently mangling your data.

Common uses

Build ?utm_source= tracking links, embed a full URL inside another URL's query parameter (a "redirect" or ?next= parameter), percent-encode an email subject for a mailto: link, escape search terms for an API call, or decode a messy copied link from an analytics dashboard. Because everything runs locally, credentials and tokens inside the URL you are debugging are never sent to any third-party service.
