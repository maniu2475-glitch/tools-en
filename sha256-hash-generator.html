About the SHA-256 hash generator

SHA-256 is a member of the SHA-2 cryptographic hash family standardized by NIST. It takes an input of any length and produces a fixed 256-bit (64 hexadecimal character) digest. Because even a one-character change produces a completely different hash, SHA-256 is widely used for data integrity checks, file fingerprints, password hashing (with proper salting), digital signatures and blockchain mining puzzles.

This page computes SHA-256, SHA-1 and SHA-512 digests using the native Web Crypto API built into every modern browser, which means the calculation is both fast and cryptographically correct. Your text is never transmitted anywhere: it stays in the tab's memory and disappears when you close it. Note that hashing is one-way - a digest cannot be reversed into the original input. SHA-1 is provided only for legacy compatibility and is considered collision-prone, so prefer SHA-256 for new work.
