About this tool

Scanning a barcode normally means installing an app, but modern JavaScript libraries such as ZXing can decode 1D barcodes straight from the webcam inside a plain web page. This scanner supports the most common retail and logistics symbologies — EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39 and ITF — which together cover product packaging, shipping labels and inventory tags. Point your camera at the code and the decoded value appears instantly with a timestamp; alternatively upload a photo of a barcode and it will be analyzed in the same tab. A common use case is price and product lookup: paste the EAN number into a search engine to identify the item. For 2D matrix codes, try our dedicated QR code scanner as well. Everything is processed locally: frames from your camera never leave the device.
