About this tool

Binary arithmetic is the foundation of every computer science course: adding two 8-bit values by hand teaches carry propagation far better than reading about it. This calculator takes two numbers in any of the bases binary, octal or hexadecimal, parses them, performs the selected operation, and prints the answer back in the same base along with its decimal equivalent so you can sanity-check the math. Invalid digits (for example typing a 2 in binary mode) are reported immediately instead of producing silent nonsense. Typical use cases include verifying two's-complement exercises, cross-checking network subnet math, debugging bit-mask arithmetic in code, and converting hex addresses while reading assembly. Because the whole computation is pure client-side JavaScript, it works offline once the page is loaded.
