About the Ratio Calculator

This ratio calculator solves the three most common ratio problems in one place. Simplify a ratio: enter values like 1920:1080 or 8:12 and get the reduced form (16:9 and 2:3) by dividing out the greatest common divisor. Solve for the missing value: given A:B = C:? or A:? = B:C, it finds the unknown using cross multiplication - perfect for scaling recipes, map scales, mixing paint or concrete, and resizing images proportionally. It also shows each ratio as a percentage split so you can divide amounts by ratio, for example sharing 900 dollars in a 2:3:4 ratio. Ratios appear everywhere in daily life: cooking (ingredient proportions), finance (debt-to-income), screen sizes (aspect ratios), maps and models (scale), and mixing solutions. All calculations run instantly in your browser with no data upload.
