About the URL Encoder & Decoder

A URL can only contain a limited set of characters, so spaces, ampersands, Chinese characters, emoji and many symbols must be percent-encoded before they can safely travel inside a URL. This tool gives you two encoding modes that mirror the JavaScript built-ins exactly. Component mode (encodeURIComponent / decodeURIComponent) escapes every reserved character, which is what you need for a single query-string value, a redirect URL passed as a parameter, or a search term containing &, # or +. Full URL mode (encodeURI / decodeURI) leaves the structural characters such as : / ? & = # alone and only escapes what would actually break the URL, so you can safely encode a whole address bar value or a path segment containing unicode. Every operation runs locally: the text you paste - including tokens, tracking parameters and private deep links - never leaves your browser. Typical uses include building utm_source / utm_campaign tracking links, fixing double-encoded URLs copied out of analytics tools, debugging a 404 caused by a space in a filename, encoding non-ASCII filenames for a web server, and preparing form values for a POST body. Round-tripping is lossless: encode then decode returns your original string byte-for-byte, and malformed percent sequences are reported instead of silently mangled.
