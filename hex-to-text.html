Hex to Text Converter

Hex → Text

Text → Hex

Hexadecimal (base-16) notation represents every byte as two characters from 0-9 and a-f, and it is the standard way to display raw binary data: in hex editors, network packet captures, debuggers, checksums and API responses. A string like 48 65 6c 6c 6f is simply "Hello" in hex form. Converting between hex and readable text is a routine task for developers, reverse engineers, and anyone working with encoded payloads or color codes.

This converter handles both directions: paste hex (with or without spaces, colons or 0x prefixes) to get the decoded ASCII/UTF-8 text, or type text to get its hex representation. The tool automatically strips common separators so you can paste hex straight from a packet dump or hexdump output, and it validates input, warning you about odd-length strings. All processing is local JavaScript - your data never leaves the browser - which matters because hex dumps often contain sensitive material like session tokens or private keys.
