YAML to JSON Converter

Convert YAML to JSON instantly, free and in your browser. Handles nested maps, lists, quoted strings, block scalars (| and >), comments, booleans, nulls and numbers.

About this tool

YAML to JSON is a free online converter that turns YAML configuration into JSON. YAML is the human-friendly format behind Docker Compose files, Kubernetes manifests, GitHub Actions workflows, Ansible playbooks, Helm charts and most CI pipelines, but nearly every programming language and HTTP API consumes JSON instead. This converter lets you paste a YAML document and immediately see the equivalent JSON object, which is exactly what you want when you are debugging a deployment file, checking whether a value is really the boolean false or the string "false", or migrating configuration from one tool to another. The parser runs entirely in JavaScript on your own device, so proprietary configuration, API tokens and internal service names never leave your browser - nothing is uploaded and nothing is logged, which makes it safe for work documents you would not paste into a random SaaS converter. Supported syntax includes nested mappings and sequences, inline flow collections such as [a, b] and {k: v}, single-quoted and double-quoted strings with escape sequences, literal and folded block scalars, comments, document start markers, nulls, booleans, integers, decimals, scientific notation and hexadecimal values. Output can be pretty-printed with two or four spaces, or minified to a single line, and the result can be copied to the clipboard or downloaded as a .json file in one click. Because the whole thing is client-side, it keeps working offline once the page has loaded and there is no file-size limit other than your browser's memory. If your document relies on advanced YAML features such as anchors, merge keys or custom tags for typed objects, the faithful route is a full YAML 1.2 library - but for everyday configuration files this page gives you the answer in milliseconds. Related converters on this site include JSON to YAML for the reverse direction, a JSON formatter for pretty-printing and validating JSON, JSON to CSV for tabular exports and JSON to TypeScript for generating interfaces.
