About this tool

JSON and CSV model data differently, which is why converting between them is fiddly. JSON is a tree of objects and arrays with typed values; CSV is a flat table of strings with a single header row. This converter expects the common case — a JSON array of objects — and takes the union of all keys as the header, so records with missing fields still line up correctly (missing values become empty cells). Nested objects are expanded into dotted column names such as user.address.city, and arrays are serialised as JSON strings inside the cell so no information is silently dropped. Cells that contain the delimiter, a double quote or a line break are wrapped in double quotes and their internal quotes doubled, exactly as RFC 4180 requires — that is what stops a value like Oslo, Norway from shifting every later column by one. The tool also auto-detects when the input is a single object (it wraps it in an array) and when it is a top-level array of primitives (it emits a single value column). Nothing is uploaded anywhere; the whole conversion runs in your browser tab.

Tips

If you are opening the result in Excel, choose the comma delimiter and be aware that Excel in some locales expects semicolons — pick that option here rather than fixing it by hand. If you are feeding the result into a database COPY or a data pipeline, prefer Tab (TSV), which avoids quoting almost entirely because tabs rarely appear in real data. To go the other way, use the CSV to JSON converter.
