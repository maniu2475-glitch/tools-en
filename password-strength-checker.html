About this tool

Almost every data breach starts with a weak password, but "weak" is hard to judge by eye — Pa$$word1 looks fancy while containing a dictionary word that cracking tools try in the first second. This strength checker scores a password the same way offline attackers think. It counts the real entropy: the character pool implied by lowercase, uppercase, digits and symbols, multiplied by the password length, then applies penalties for repeated characters, sequential runs like "abcd" or "1234", and common passwords from a small embedded top-list. The result is a 0–100 score with a color bar, a plain-language verdict, and an estimated brute-force time assuming a modern GPU rig at roughly 100 billion guesses per second — the ballpark used in published hash-cracking benchmarks. Practical tips appear for every weakness found: add length (the single biggest factor), mix character classes, avoid dictionary words and avoid keyboard patterns. The page is 100% static and contains no network calls, so you can safely paste a real password — although best practice is always to test a similar-shaped one. Pair it with the built-in random password generator for actually creating strong keys.
