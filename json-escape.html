About this tool

JSON string literals have strict escaping rules. A double quote inside the text must be written as \", a backslash as \\, and control characters must be encoded - a newline becomes \n, a tab \t, and any non-ASCII character may be written as a \uXXXX escape. Whenever you need to place a piece of text inside a JSON document, a JavaScript string, a log format or a database column typed as JSON, you have to apply those rules correctly or the parser will reject the whole document.

This tool handles both directions. The Escape button takes whatever you paste and produces a valid JSON string literal, using the browser's native JSON.stringify so the output is guaranteed to be spec-compliant. The Unescape button takes an escaped string - with or without the surrounding quotes - and turns it back into readable text, decoding unicode escapes, newlines, tabs and escaped quotes.

Common real-world uses: preparing a snippet of HTML or SQL for embedding in a JSON config file, escaping a Windows file path (C:\Users\name) so it can live inside JSON, cleaning up API responses that arrive with escaped bodies, or reading a stack trace that has been double-encoded. Because the escaping is performed with the platform's own serialiser, characters such as emoji and accented letters produce identical results to what JavaScript, Python, Go and most other languages expect.

Note that escaping is not the same as minifying: to re-indent or validate a whole JSON document use the JSON formatter; to turn JSON into query-friendly CSV use JSON to CSV.

Frequently asked questions

What is the difference between escaping and encoding?

Escaping rewrites characters so they are legal inside a JSON string (quotes, backslashes, control characters). Encoding (such as Base64 or URL encoding) transforms the whole byte stream for a different transport.

Should I keep the surrounding double quotes?

Keep them if you are pasting the result into a JSON document as a string value. Remove them if you need just the inner content.

Does it handle unicode and emoji?

Yes. Escaping uses JSON.stringify, which outputs UTF-8 characters directly or \uXXXX sequences depending on the character.

Is my data sent to a server?

No. The conversion runs entirely in JavaScript on this page.
