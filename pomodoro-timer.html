About this tool

The Pomodoro Technique, invented by Francesco Cirillo in the late 1980s, splits work into 25-minute focused sprints separated by 5-minute breaks; after four cycles you take a longer 15–30 minute rest. This online Pomodoro timer implements the classic cycle in a single page: a large countdown, a phase label telling you whether you are focusing or resting, adjustable focus and break durations, an audible beep at every transition, and a counter of completed pomodoros kept in localStorage so your tally survives page reloads. Because the timer is a static page running entirely in your browser, you can keep it in a pinned tab all day without any server knowing your work habits. It pairs nicely with a to-do list: write down one task per pomodoro and start the timer.
