JSONPath Evaluator

Paste JSON, write a JSONPath expression, and instantly see every match. Supports root $, child .key, wildcards, recursive descent .. and filter expressions [?(@.price < 10)].

About this tool

JSONPath is a lightweight query language for JSON, roughly the JSON equivalent of XPath. Instead of walking a structure by hand in code, you describe the path you want and the evaluator returns every node that matches. It is widely used in API testing, log filtering, ETL preprocessing and configuration tooling.

The syntax is small but expressive. $ is the root of the document. .store selects a child property, [*] or .* selects all children, and .. performs a recursive descent so that $..price finds every price field at any depth. Filters such as $.items[?(@.price < 10)] keep only elements whose members satisfy a comparison; comparisons support the usual operators plus existence checks and boolean combinations with && and ||. Index slices like [0:3] and negative indices such as [-1:] work as well.

This page implements the common subset of the specification, including recursive descent, wildcards, numeric indices, slices and filter expressions, and it renders the complete match set as JSON so you can copy it straight into a test assertion or a script. If an expression matches nothing you get an empty array rather than an error, which distinguishes "no match" from "malformed query" — syntax problems are reported separately with the position that failed.

All parsing and evaluation happens in your browser using JavaScript. Nothing is uploaded, so it is safe to paste production payloads, tokens or customer records while debugging. Very large documents may take a moment because evaluation walks the whole tree for recursive queries.
