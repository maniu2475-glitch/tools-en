Unicode Text Converter

See exactly how your text is represented as JavaScript \u escapes, HTML entities, percent-encoded UTF-8 or raw bytes - and convert back with one click.

About this tool

Text on screen and text stored in a file are two different things. A single visible character such as an em dash, an accented e or a Chinese ideograph may occupy one byte, two bytes, three bytes or a surrogate pair depending on the encoding, and each programming environment offers a different escape syntax for writing it in ASCII-only source code. This page shows you all of those representations side by side so you can copy the one your code, configuration file or URL actually needs.

The JavaScript mode produces \uXXXX escapes for the Basic Multilingual Plane and a surrogate pair for anything above it, which is what you need inside a JSON string or a JavaScript literal that has to survive a non-UTF-8 transport. The HTML mode emits decimal numeric character references that render identically in any browser. Percent encoding applies UTF-8 first and then escapes every byte, matching what a URL query string does in practice. The hex mode prints the raw UTF-8 bytes, which is useful when you are staring at a corrupted log file and need to know which bytes are actually there. The U+ mode lists code points with their hexadecimal values, the notation used in Unicode documentation and character tables.

Decoding is automatic: paste in \u sequences, &#NNNN; entities, %E4%BD%A0 style percent escapes, a hex byte dump or U+ notation and the tool figures out which one you gave it. Mixed input is handled too, because scraped text often arrives with some characters already escaped and others not.

Typical uses are fixing mojibake in a database export, writing a translation file that must stay ASCII, checking whether two visually identical strings really contain the same code points, and debugging why an emoji split into two halves after passing through a system with a 3-byte UTF-8 limit. Everything happens in your browser, so you can paste customer data or private messages without them leaving the machine - just remember that visual similarity is not identity: Cyrillic and Latin letter A look the same on screen and are different code points, and this tool will show you that instantly.
