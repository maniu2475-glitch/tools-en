ROT13 & Caesar Cipher

ROT13 / Caesar cipher

ROT13 (rotate by 13 places) is a simple letter substitution cipher that replaces each letter with the letter 13 positions after it in the alphabet. Since the English alphabet has 26 letters, applying ROT13 twice returns the original text, which makes it its own inverse - the same function encodes and decodes. This classic cipher appears everywhere from newsgroups hiding spoilers to programming puzzles and CTF challenges. Because A maps to N, B to O, and so on, the result looks like scrambled nonsense to a casual reader while remaining trivially reversible.

This tool also implements the general Caesar cipher with any shift value from 1 to 25, so you can try ROT1, ROT5, ROT13, ROT18 and every other rotation. Type or paste text, choose a shift, and see the encrypted (or decrypted) result instantly. Case is preserved, digits and punctuation are left untouched. Everything runs client-side in JavaScript - no data is ever sent to a server - making it safe for any content. Useful for decoding hidden messages, obfuscating puzzle answers, teaching classical cryptography, or verifying ROT13 text found in documentation and forum posts.
