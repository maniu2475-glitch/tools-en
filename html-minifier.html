About this tool

An HTML minifier removes everything a browser does not need: HTML comments, indentation, repeated spaces and newlines between tags. These characters are invisible to visitors but they are still transferred over the network and parsed by the browser, so trimming them reduces page weight and can shave tens of milliseconds off time-to-first-byte on slow mobile connections. A typical hand-written page shrinks by 10% to 35% depending on how heavily it is indented and commented.

This tool runs entirely in your browser with no upload step, so you can safely minify internal templates, email HTML or customer pages that you cannot paste into a third-party service. It applies three independent passes: comment removal (with <!-- --> blocks and conditional-comment safety), whitespace collapsing between tags while preserving the contents of <pre>, <textarea> and <script>, and an optional pass that drops quotes around single-token attribute values where HTML5 allows it.

Before deploying, always confirm the minified page renders identically. Whitespace inside inline elements such as a <span> followed by another <span> is significant (it produces a visible space), so aggressive collapsing can occasionally join two words together. If that happens, disable the whitespace checkbox or keep a space inside the first inline element. Minification is lossless for structure but not always lossless for typography.

For best production results, combine this tool with gzip or Brotli on your web server - minifying first and compressing second always beats compressing the original source. CSS and JavaScript files should be minified separately with the CSS minifier and JS minifier.
