About this tool

Unix file permissions are written as a 3- or 4-digit octal number, e.g. 755. Each digit controls one class of user: the owner, the group and others. The value of each digit is the sum of read=4, write=2 and execute=1. So 7 = 4+2+1 = rwx, 5 = 4+1 = r-x and 4 = r--.

A leading 4th digit sets the special bits: 4 = setuid (SUID), 2 = setgid (SGID), 1 = sticky bit, so 4755 means SUID + 755, and 1777 is the classic sticky-bit directory (like /tmp). The symbolic form (-rwxr-xr-x, chmod u+x) is mapped one-to-one with the numeric form above.

Common values: 644 regular files, 600 private keys and secrets, 755 directories and executables, 700 private directory, 775 shared by group, 777 world-writable (risky).
