About this tool

The SQL formatter takes a cramped, one-line query — the kind copied from logs, generated by ORMs, or written under deadline pressure — and re-indents it into a form humans can actually read. Keywords such as SELECT, FROM, WHERE, GROUP BY, ORDER BY, HAVING, JOIN and set operators each start a new line, and nested parentheses inside IN lists, CASE expressions and subqueries get an extra level of indentation so the query's structure is visible at a glance. Formatting does not change what a query does; it changes only whitespace, so the result is safe to paste straight into your database console, a migration file, a code review, or documentation. It handles SELECT, INSERT, UPDATE, DELETE and CREATE TABLE statements, uppercases major keywords for convention, and preserves string literals and quoted identifiers intact. Everything runs in JavaScript in your browser, so proprietary or confidential SQL never touches a server.
