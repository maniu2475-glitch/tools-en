About this tool

Need an API key, a test fixture, a coupon code, or a one-time token? This generator produces random strings of any length using the exact character sets you choose, and it sources its randomness from the browser crypto API (crypto.getRandomValues) rather than Math.random - the same primitive used for real cryptographic key material. That makes the output suitable for session identifiers, salts, and other security-sensitive values, not just placeholder text. Generate up to 100 strings at once, mix uppercase, lowercase, digits and symbols, and copy everything with one click. For human-memorable secrets, prefer the dedicated password generator; for raw entropy, use this tool.
