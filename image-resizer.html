About this tool

Resizing images is one of the most common everyday tasks: shrinking a photo before emailing it, fitting a picture into a website header, meeting an upload limit on a job portal, or preparing an avatar for a social network. Most people reach for desktop software or upload private photos to an unknown website, which is slow and often a privacy risk.

This tool solves that by doing all of the work locally. When you select a file it is read with the browser's built-in FileReader API and drawn onto a canvas element at the size you specify. The canvas is exported back to PNG, JPEG or WebP using toDataURL. Nothing is transmitted over the network, so there is no upload wait, no server-imposed file-size limit, and no chance of your image being logged or reused by a third party.

Key features: exact width and height inputs, an optional aspect-ratio lock so pictures never look stretched, a quality slider that matters for JPEG and WebP output, and a format selector so you can convert as you resize (a large PNG screenshot can come out as a compact WebP). The canvas preview updates in place and the download button saves the result with a descriptive file name that includes the new dimensions.

Typical uses include reducing 4000-pixel camera photos down to 1200 pixels for the web, generating thumbnails, preparing images for Markdown documents, and fitting pictures into a strict pixel budget. Because scaling happens in the browser with high-quality smoothing enabled, results look clean for both upscaling and downscaling. If you need to shrink file size rather than pixel dimensions, try the image compressor; for format conversion without resizing, see PNG to JPG.

Frequently asked questions

Are my images uploaded anywhere?

No. All decoding, resizing and encoding happens in your browser. You can disconnect from the internet after the page loads and the tool still works.

What is the maximum image size?

It depends on your browser's memory, but images up to roughly 50 megapixels usually work. Very large panoramas may be slow on older phones.

Does resizing reduce file size?

Usually yes, especially with JPEG or WebP output. Lowering the quality slider also lowers file size; WebP at about 0.8 quality gives the smallest files.

Can I resize to exact dimensions such as 1920x1080?

Yes. Type the width and height you need, uncheck "keep aspect ratio" if the target ratio differs, then press Resize.
