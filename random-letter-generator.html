About this tool

Random letters power a surprising range of everyday needs: teachers pick letters for alphabet games and phonics drills, players of Scattergories or word games need a fair draw, linguists sample characters for experiments, and developers test input forms with unusual data. Rolling physical letter dice is slow and biased; a cryptographic random source is neither.

This generator draws from the browser's crypto.getRandomValues, the same high-quality randomness used for security, so every letter has an exactly equal chance. Choose uppercase, lowercase, or both; generate up to 500 letters at once; and toggle whether repeats are allowed — with repeats off, the tool performs a fair without-replacement draw from a shuffled bag, like dealing cards.

The custom set field unlocks specialized uses: enter AEIOU for vowel-only draws, enter your own alphabet for non-English scripts, or paste a subset like QWERTYUIOP for keyboard-row games. All generation happens locally; nothing is transmitted.

A classic use is the A-Z challenge: generate one letter and name an animal, food and city starting with it. With the count field you can generate a whole game round in one click.

FAQ

How random is it?

It uses the browser's cryptographic random number generator, giving an exactly uniform distribution.

Can I generate from vowels only?

Yes — type AEIOU into the custom set field.

Can I get letters without repeats?

Uncheck 'Allow repeats' for a fair without-replacement draw.
