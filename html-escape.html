About the HTML Escape & Unescape

When you paste user-supplied text, code samples or CMS content into a web page, the characters < > & " and ' are not safe to insert literally: a < may open a tag, an & may start an entity, and a quote can break out of an attribute - the classic cross-site scripting (XSS) pattern. This tool escapes those five characters into their named HTML entities (&lt; &gt; &amp; &quot; &#39;) so the browser displays them as text instead of interpreting them as markup, and it reverses the process so you can turn a block of encoded HTML back into readable source. The numeric mode converts every non-ASCII character to a decimal (&#NNNN;) or hex (&#xNNNN;) reference, which is useful for email templates and legacy systems that mangle UTF-8. The named-entity decoder recognises the full set of common named entities - &nbsp; &copy; &mdash; &hellip; &euro; &trade; and hundreds more - so scraped pages and RSS feeds turn back into clean text. A few typical jobs: making a code snippet display correctly inside a <pre> block, fixing descriptions exported from a database that stored entities, preparing a value for a JavaScript string literal, and showing raw markup in a blog post. Everything is processed on your machine; the text - which may contain private customer data - is never uploaded.
