About this tool

Working out a tip at the table is surprisingly error-prone: percentages, rounding, and splitting between five friends all at once. This tip calculator handles the whole job in one step. Enter the pre-tip bill, pick a common percentage button (10%, 15%, 18% or 20%) or type any custom rate, and set the number of diners.

The output shows the tip amount, the total including tip, and the amount each person owes. Results are rounded to two decimals in a way that always covers the bill, so groups never come up short. It works with any currency because you simply type amounts in whatever currency the bill uses.

Tipping customs differ widely: 15-20% is typical in the United States, 10% in many European countries, and Japan traditionally expects none. The quick percentage buttons make it easy to adapt to wherever you are eating. All math happens locally in your browser, so nothing is transmitted anywhere.

FAQ

How much should I tip?

US custom is 15-20% for restaurant service; many other countries are 5-10%. Pick the button that matches your local custom.

Can I split an uneven bill?

This tool splits evenly. For per-item splitting, divide each person's items first, then run each subtotal through the calculator.

What currencies are supported?

All. The tool only does arithmetic on the number you type, so use any currency.
