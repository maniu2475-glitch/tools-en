Morse Code Translator

Text → Morse

Morse → Text

Morse code is a time-honored encoding system that represents letters, digits and punctuation as sequences of dots (short signals) and dashes (long signals), invented for telegraphy in the 1830s and still used today by amateur radio operators, aviation beacons, and in emergency situations - the famous SOS distress signal is Morse code. Each letter maps to a unique pattern, for example A is .-, B is -..., and numbers each use five symbols.

This translator works in both directions: paste plain text and get International Morse code, or paste Morse (separate letters with spaces, words with /) and get readable text back. Type your message in the box and the conversion happens instantly as you type. You can also play the Morse audio using your browser's built-in sound synthesis, which is handy for learning or signaling practice. All conversion happens locally in JavaScript, so nothing is uploaded anywhere and the tool works offline once loaded.
