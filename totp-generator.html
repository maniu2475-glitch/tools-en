About the TOTP Code Generator

This tool generates time-based one-time passwords (TOTP) exactly like Google Authenticator, Authy or Microsoft Authenticator, but locally in your browser. Paste the Base32 shared secret that a website shows you when you set up two-factor authentication, and the page computes the current 6- or 8-digit code with the standard algorithm from RFC 6238 (HMAC-SHA1 over a moving 30- or 60-second counter, then dynamic truncation). The countdown shows how many seconds remain before the code rolls over. Developers use it to verify their own TOTP implementation without installing an app; admins use it to recover access when a phone is lost and only the secret is available. The page includes a built-in self-test that recomputes the RFC 4226 reference vector (counter 1 must yield 94287082) so you can confirm the implementation is correct. Security note: the secret never leaves your device because all cryptography runs in JavaScript in your tab - but for maximum safety, avoid pasting production secrets into any website, including this one, and prefer setting up a fresh test secret.
