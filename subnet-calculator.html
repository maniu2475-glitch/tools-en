About this tool

A subnet calculator takes an IP address in CIDR notation — for example 192.168.1.10/24 — and derives every parameter of the network it belongs to: the network address, broadcast address, usable host range, subnet mask, wildcard mask and the total number of usable hosts (2 to the power of the host bits, minus two, because the network and broadcast addresses are reserved). The /24 in the example means the first 24 bits are fixed as the network portion, leaving 8 bits for hosts and therefore 254 usable addresses. Network engineers, homelab owners and students preparing for certifications like CCNA use this daily when planning address space. The entire calculation is bitwise arithmetic done in your browser, so nothing is sent to any server.
