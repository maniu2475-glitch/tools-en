The ASCII table in one paragraph

ASCII — the American Standard Code for Information Interchange — was published in 1963 as a seven-bit character encoding and it remains the substrate under nearly every text format used today. Codes 0 to 31 plus 127 are non-printing control characters inherited from teletype machines: 0x0A is line feed, 0x0D is carriage return, 0x09 is tab, and the notorious 0x07 rings an actual bell on old terminals. Codes 32 to 126 are the printable set that starts with space, runs through digits and punctuation, and ends with the tilde at 126. The ordering is not arbitrary: uppercase letters occupy 65 to 90 and lowercase occupy 97 to 122, a gap of exactly 32, so flipping bit 5 of a letter toggles its case — a trick still used in fast text algorithms.

Why hexadecimal and binary matter

Developers meet ASCII in three different costumes. Protocols and file formats usually speak hex, so a space shows up as 0x20 and a newline as 0x0A; that is what you will see in a packet capture or a hex editor. Decimal codes appear in HTML numeric entities such as &#65; and in programming-language escapes. Binary is where bit-level codecs like Base64 and compression live — Base64 exists precisely because it maps every six bits onto an ASCII-safe subset of 64 printable characters. Being able to move between the three representations without guessing is the fastest way to debug mojibake, mismatched line endings and stray non-breaking spaces.

Extended characters and the road to Unicode

ASCII stops at 127. Codes 128 to 255 belong to the extended ranges: ISO-8859-1 (Latin-1) assigns Western European accented letters, while the CP437 and Windows-1252 variants reuse the same slots for box-drawing symbols and smart quotes. This ambiguity is exactly why "smart quotes" from a word processor break JSON: they are byte 0x92 in Windows-1252, not an ASCII apostrophe. Modern text is Unicode, and UTF-8 deliberately keeps the first 128 code points identical to ASCII, which is why a plain English file is byte-for-byte valid UTF-8. When you need to move between these representations, pair this table with the hex to ASCII converter, the Base64 encoder and the binary to text tool.

Handy landmarks to memorise

  • 48–57 digits 0–9 — subtract 48 to get the integer value
  • 65–90 uppercase, 97–122 lowercase — difference 32
  • 32 space, 9 tab, 10 LF, 13 CR
  • 64 at sign, 91 left bracket, 96 backtick, 123 curly brace
