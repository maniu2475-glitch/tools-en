About this tool

YAML is the configuration format of choice for Kubernetes, Docker Compose, Ansible and GitHub Actions, while JSON dominates APIs and package files. Converting between the two is a routine task for every developer, and this tool removes the tedious manual reformatting. Paste any valid JSON — objects, arrays, nested structures, numbers, booleans, nulls — and receive clean two-space-indented YAML.

The converter runs a full JSON.parse validation first, so malformed input gives you a precise error message with position instead of silently producing broken YAML. Strings are emitted bare when possible, and empty arrays and objects are rendered compactly as [] and {} to keep output idiomatic.

Because the conversion is pure JavaScript in the browser, your configuration files — which often contain credentials or internal hostnames — never touch a server. This makes the tool safe for real production configs, unlike paste-it-online services of unknown provenance.

FAQ

Is my config data uploaded?

No. Parsing and conversion happen entirely in your browser.

What happens with invalid JSON?

You get the parser's error message including the position, so you can fix the JSON first.

Does it handle deep nesting?

Yes, any depth of objects and arrays is supported.
