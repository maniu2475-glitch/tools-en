About the SHA-1 Hash Generator

SHA-1 (Secure Hash Algorithm 1) produces a fixed 160-bit / 40-character hexadecimal digest from any input. This tool computes it with the browser's native Web Crypto API, so the text you paste is hashed on your own machine and never transmitted. Type or paste text and the 40-character hex digest updates on every keystroke; a character and UTF-8 byte counter is shown alongside so you can confirm what exactly was hashed (Unicode characters take two or more bytes, and a trailing newline changes the digest). SHA-1 is no longer considered collision-resistant - in 2017 the SHAttered attack produced two different PDFs with the same SHA-1 hash - so it must not be used to store passwords, sign certificates or design new protocols. It is still widely encountered in practice, though: Git uses SHA-1 to identify commits, trees and blobs (a commit hash like 3f786850e387550fdab836ed7e6dc881de23001b is a SHA-1 of the commit object); old checksums, ETags, deduplication keys and legacy database indexes are still SHA-1; and many tutorials ask for the SHA-1 of a string to check whether two files are byte-identical. Use this tool to verify those legacy values, compare two strings, or paste a hex digest to confirm it is 40 valid hex characters. For anything security-sensitive, prefer the SHA-256 generator instead.
