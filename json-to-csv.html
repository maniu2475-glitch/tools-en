JSON to CSV Converter

Paste a JSON array of objects and convert it into CSV format instantly, ready for Excel or Google Sheets.

About this JSON to CSV converter

JSON (JavaScript Object Notation) is the de-facto data format for web APIs, but spreadsheets like Excel and Google Sheets expect tabular data such as CSV (comma-separated values). This converter bridges the gap: paste any JSON array of objects and it flattens the structure into rows and columns automatically. The column headers are collected from every record, so fields that appear only in some objects are still included, and missing values simply become empty cells.

Values are escaped according to the CSV standard (RFC 4180): commas, double quotes and line breaks inside a value are wrapped in quotes, and embedded quotes are doubled. Nested objects and arrays are serialized as JSON strings so you never lose information. Large inputs are handled smoothly because everything runs in your own browser with no upload, no server round-trip and no size quota. Typical use cases include exporting API responses for reporting, preparing test fixtures, and moving data between JavaScript apps and spreadsheet workflows.
