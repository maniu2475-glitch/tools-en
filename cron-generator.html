About this tool

Writing cron expressions from memory is error-prone: is Sunday 0 or 7, does the month field come before the weekday, what does */10 in the hour field do? This generator lets you fill each of the five crontab fields separately and shows the assembled expression instantly, so you can paste it into crontab, Kubernetes CronJob specs, Jenkins scheduled jobs, or GitHub Actions schedules. Presets for the most common patterns - every 5 minutes, weekday mornings, weekly and monthly runs - help you start from a known-good example. The fields also accept advanced syntax such as ranges (1-5), lists (1,15), steps (*/10) and names (MON-FRI, JAN). Pair it with the cron expression parser tool to double-check what your final expression actually means before it goes to production.
