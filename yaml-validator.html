About the YAML Validator & Formatter


YAML looks friendly but is unforgiving: a single tab, a misplaced colon or an off-by-one indent silently changes the meaning of a document or makes it fail to parse entirely - and the error message you get from Kubernetes, GitHub Actions, Ansible or Docker Compose rarely tells you which line is guilty. This validator parses your YAML in the browser and reports the first structural problem with its line and column, along with the parser's explanation. It separately detects the most common invisible killer: tab characters used for indentation (YAML forbids them outright, and the error message you get from CI systems is usually misleading about this). It also flags duplicate keys in the same mapping, which most parsers silently accept by keeping the last value - a classic cause of a config that 'looks right' but behaves wrongly. When the document is valid, the tool pretty-prints it as JSON so you can visually confirm the resulting tree: arrays stay arrays, quoted numbers stay strings, and anchors and aliases are expanded. That makes it a fast way to double-check that a boolean like 'no' did not become the string 'no', or that an unquoted version number 1.10 was not read as 1.1. Everything runs locally: your manifests, workflow files and secrets-in-config never leave the browser.
