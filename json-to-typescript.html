About this tool

Typing API responses by hand is slow and error-prone. Paste a JSON sample and this tool generates ready-to-paste TypeScript interfaces: nested objects become their own interfaces, arrays are detected from their element type, and primitive fields get string / number / boolean / null types.

It handles arrays of objects, arrays of arrays and mixed JSON, renames unsafe keys to valid identifiers and names nested interfaces after their parent key. Everything runs locally - safe for private API payloads.
