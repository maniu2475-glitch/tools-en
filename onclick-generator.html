Onclick Generator

Pick an action, fill in the options and get correct, escaped JavaScript onclick code you can paste straight into a button, link or image tag.

About this tool

Inline event handlers are the fastest way to attach behaviour to a piece of HTML when you are working in a CMS, an email template builder, a legacy page you cannot add scripts to, or a quick demo. The syntax looks trivial, which is exactly why it goes wrong: a message containing an apostrophe breaks a single-quoted attribute, a double quote inside the handler ends the attribute early, and a selector with a hash makes the whole thing decode as a fragment. This generator quotes and escapes everything for you so the resulting attribute is valid in both HTML and JavaScript.

The available actions cover the requests that come up most often: a plain alert, a confirm dialog that reports what the visitor chose, navigation in the same tab or in a new one, copying a fixed string to the clipboard, smooth scrolling to a named element, toggling an element's visibility, changing an inline style, and logging to the console for debugging. Each one maps to a short, dependency-free snippet that works in every modern browser without a framework.

Two HTML details are handled automatically. First, the tool always adds return false; to navigation actions, because otherwise the browser follows the default behaviour of the anchor and you end up with a blank page instead of a new tab. Second, single quotes are used inside the handler and double quotes outside it, with entities applied to any conflicting character; the escape-order matters, and getting it wrong is the single most common cause of a handler that silently does nothing.

Keep in mind that inline handlers run in the global scope, cannot be removed or reused as easily as listeners added with addEventListener, and may be blocked outright by a strict Content-Security-Policy that disallows 'unsafe-inline'. For production code where you control the script, prefer attaching listeners in JavaScript. Use this page for the cases where inline is the only option - and when you do, remember that generated code is only a starting point: review it before shipping, especially the clipboard action, which needs the page to be served over HTTPS to work.
