About this tool

Linux and macOS file permissions trip up almost every beginner: is 755 read-write-execute for the owner? Which digit is the group? This chmod calculator lets you toggle read, write and execute checkboxes for owner, group and others, and instantly shows the numeric octal mode (such as 755), the symbolic string (rwxr-xr-x), and a sentence explaining exactly what each class of user can do. You can also type a numeric mode like 644 and the checkboxes will update, making it easy to reverse-engineer permissions you find in tutorials or deployment guides. The results are safe to paste into chmod commands, Dockerfiles, Git hooks and Ansible playbooks. Everything runs client-side, so no file data ever leaves your machine.
