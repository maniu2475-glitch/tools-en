Regex Tester

Live match highlighting & list — everything runs in your browser, nothing is uploaded.

About this tool

Regular expressions are powerful but notoriously hard to read, and the fastest way to learn them is to experiment. Paste a pattern, choose your flags, and this tester highlights every match inside your sample text in real time, listing each match with its index and captured groups. It uses the standard JavaScript RegExp engine (with the g, i, m and s flags available as checkboxes), so behaviour matches what you will get in browser code and Node.js exactly. Invalid patterns produce a readable error message instead of a silent failure, which makes this a great companion for debugging validation rules, find-and-replace commands, log scraping scripts or URL routing patterns. Nothing is sent to a server - the engine lives entirely in your browser tab.
